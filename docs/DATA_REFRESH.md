# Transit Data Refresh

## Why refresh is required

The application bundles CTB, GMB and MTR topology so users do not depend on a project server. The bundled snapshots become stale and must be regenerated by a maintenance agent with internet access.

The supplied GMB snapshot is legacy. Production deployment must replace it because older entries do not retain the numeric route ID, route sequence and stop sequence required by the precise GMB route-stop ETA endpoint.

## Command

```bash
npm run data:refresh
```

The script writes:

- `src/data/ctb.json`
- `src/data/gmb.json`
- `src/data/mtr_stations.csv`

## Expected GMB schema

```json
{
  "schemaVersion": 2,
  "generatedAt": "ISO timestamp",
  "routes": [
    {
      "route": "routeCode~numericRouteId-O",
      "bound": "O",
      "sourceRouteId": "numeric id",
      "routeSeq": 1
    }
  ],
  "routeStops": [
    {
      "route": "routeCode~numericRouteId-O",
      "bound": "O",
      "stopId": "stop id",
      "sourceRouteId": "numeric id",
      "routeSeq": 1,
      "stopSeq": 4
    }
  ]
}
```

## Validation

```bash
npm run verify:handoff
```

The internal GMB route key includes the numeric route ID so parallel variations cannot be stitched together accidentally. The UI removes that internal suffix before showing the route number to passengers.

The verifier emits a warning while the GMB snapshot is legacy. After refresh, inspect several records and query real ETA for both directions.

## MTR coordinate caveat

The official line/station catalogue used by the current script does not populate coordinates in this project. MTR stations borrow coordinates only when stop merging finds a geographically valid equivalent provider stop. A future data task should install a licensed/official MTR station coordinate catalogue and add a regression check that every active station has non-zero coordinates.

## Update cadence

Refresh before each public release and whenever an operator changes routes/stops. Do not refresh from every end-user device; it is a maintenance/build operation.
